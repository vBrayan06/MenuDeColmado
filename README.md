<img width="796" height="477" alt="image" src="https://github.com/user-attachments/assets/b21fb46b-1c06-462b-984f-833af215b70c" /># Sistema de Facturacion - Colmado La Fuerza

Aplicacion de escritorio desarrollada en C# utilizando Windows Forms como parte de un ejercicio de programacion. El proyecto simula un sistema basico de facturacion para un colmado, permitiendo calcular el monto total de una compra en pesos dominicanos (RD$).

---

## Descripcion del proyecto

El programa consta de una interfaz grafica interactiva diseñada para agilizar el calculo de ventas mediante los siguientes elementos:

* Lista de productos (ComboBox): Contiene un menu de canasta basica precargado, donde cada opcion incluye su nombre y precio unitario asignado.
* Cantidad (TextBox): Campo numerico donde el usuario ingresa el volumen de unidades que desea comprar del producto seleccionado.
* Metodo de pago (RadioButton): Grupo de opciones mutuamente excluyentes que permite seleccionar la forma de pago de la compra (Efectivo, Tarjeta o Transferencia).
* Calculo del total (Label): Etiqueta de texto que muestra el monto final resultante al presionar el boton de calcular, indicando el total a pagar y el metodo de pago seleccionado.
